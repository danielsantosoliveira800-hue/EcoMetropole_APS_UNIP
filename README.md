# EcoMetropole 🌿

Jogo 2D educacional desenvolvido em Java com POO — APS UNIP

## Sobre o Projeto

EcoMetropole é um jogo de ação top-down onde o jogador deve coletar
recursos sustentáveis e evitar resíduos tóxicos para salvar a metrópole,
controlando os índices de sustentabilidade e poluição.

## Tecnologias

- Java (Swing / Graphics2D)
- Programação Orientada a Objetos

## Conceitos de POO Aplicados

- **Herança** — `Jogador`, `Item` e `NuvemToxica` estendem `Entidade`
- **Polimorfismo** — lista de `Entidade` trata objetos diferentes uniformemente
- **Abstração** — classe abstrata `Entidade` define o contrato base
- **Encapsulamento** — atributos privados com getters/setters
